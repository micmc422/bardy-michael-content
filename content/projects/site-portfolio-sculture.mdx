**Lou Henix**, sculptrice contemporaine, souhaitait un portfolio qui sublime son travail sans l'écraser sous la technique. J'ai conçu un site **Next.js** sobre et fluide, où les animations **Framer Motion** servent l'œuvre plutôt que de la distraire.

## 🎯 Objectifs

* Mettre en avant les œuvres et le parcours de l'artiste
* Proposer une navigation **claire et immersive**
* Refléter l'esthétique et la sensibilité de Lou Henix par le design

## 📋 Vue d'ensemble

| Élément | Détail |
| --- | --- |
| Artiste | Lou Henix — sculpture contemporaine |
| Rôle | Développeur front-end |
| Style | Minimaliste & immersif |
| Animations | Framer Motion |
| Hébergement | Vercel |

## 🧩 Fonctionnalités clés

* **Design soigné** avec animations fluides grâce à *Framer Motion*
* **Responsive design** pour une accessibilité optimale sur tous les écrans
* **SEO-friendly** pour une meilleure visibilité en ligne
* **Accessibilité** conforme aux standards web

## ⚙️ Stack technique

| Technologie | Usage | Type |
| --- | --- | --- |
| Next.js | Framework React orienté performance | Framework |
| Tailwind CSS | Design responsive et rapide à mettre en place | Style |
| Framer Motion | Animations modernes et naturelles | Animation |
| PostgreSQL | Base de données pour les contenus | Données |
| Vercel | Déploiement et hébergement | Infra |

## ⚡ Défis relevés

* Traduire le **style artistique** de Lou Henix dans une interface web cohérente
* Équilibrer **esthétique, performance et ergonomie**
* Servir les œuvres (images lourdes) sans pénaliser la vitesse
* Respecter les préférences de mouvement réduit (accessibilité)
