Commandée par l'Université Champollion (Albi), cette plateforme pédagogique accompagne les étudiants de **Licence 3** dans la découverte des technologies web modernes. L'enjeu : transformer un support de cours classique en un véritable parcours interactif, accessible et évolutif — directement rédigé en MDX.

## 🎯 Objectifs

* Offrir un support de cours **structuré et accessible**
* Intégrer des contenus **interactifs** (quizz, exercices, TL;DR)
* Favoriser l'**autonomie** et la progression des étudiants
* Mettre en œuvre une approche pédagogique **moderne et évolutive**

## 📋 Vue d'ensemble

| Élément | Détail |
| --- | --- |
| Public | Étudiants L3 — Université Champollion (Albi) |
| Rôle | Développeur & concepteur pédagogique |
| Format | Plateforme de cours interactive (MDX) |
| Périmètre | 6 modules thématiques |
| Livrable | Plateforme en ligne + activités (quizz, exercices) |

## 🧩 Contenus abordés

* **Docker** : conteneurisation et gestion d'environnements
* **Node.js** : développement backend asynchrone
* **Git & GitHub** : gestion de versions et collaboration
* **MongoDB** : bases de données NoSQL
* **GraphQL** : requêtes API flexibles
* **Authentification** : sécurisation des applications web
* **React & Next.js** : développement frontend moderne
* **UX/UI & Accessibilité** : conception d'interfaces inclusives

## ⚙️ Stack technique

| Technologie | Usage | Type |
| --- | --- | --- |
| Next.js | Rendu SSR/SSG des pages de cours | Framework |
| MDX | Contenu Markdown + composants React | Contenu |
| TypeScript | Typage statique | Langage |
| Tailwind CSS | Design responsive et moderne | Style |
| Vercel | Déploiement et hébergement | Infra |
| pnpm | Gestion des dépendances | Outil |
